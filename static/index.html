    ◆ READOUT 03 / PIPELINE

    How it reads a sentence

    1. 01

      Clean

      Text is lowercased, apostrophes dropped, punctuation stripped — matching exactly how the training data was prepared.

    2. 02

      Tokenize

      Each surviving word is mapped to an integer ID from the vocabulary the tokenizer learned during training.

    3. 03

      Pad

      The sequence is trimmed or padded to a fixed length of 50 tokens so the model always sees a uniform shape.

    4. 04

      Predict

      A bidirectional GRU reads the sequence forward and backward, then outputs a probability for each of six emotions.
